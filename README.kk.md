# wmarka clean

[Русский](README.md) · **Қазақша** · [English](README.en.md)

Joomla 5 және 6 нұсқаларына арналған, UIkit 3 негізіндегі таза бастапқы шаблон — **бірде-бір баптауы жоқ**. Беттің құрылымы `index.php` файлында, суреттердің өлшемі екі макетте, безендіру бір стиль файлында жазылған. Өзгерткіңіз келген нәрсенің бәрі әкімшілік панельде емес, файлдарда өзгертіледі.

Шаблон — [wmarka](https://github.com/bsakhanov/wmarka) шаблонының таза жинағы: позициялары сол, блоктарға, кестелерге және суреттерге көзқарасы сол, бірақ жүзден астам параметрі бар панель, жеке SEO қозғалтқышы және токендермен жасалған мегамәзір жоқ. Ол сайтты қолмен жинайтын, белгілеудің әр жолын көргісі келетін әзірлеушіге арналған.

| | wmarka clean | wmarka |
|---|---|---|
| Әкімшілік панельдегі баптаулар | жоқ | 120-дан астам параметр, мәзір пункттеріндегі опциялар |
| Превью өлшемі | `intro_image.php` және `full_image.php` макеттерінде | шаблон стилінде |
| Блог, тегтер, мақала | қатаң макеттер | түрі баптауда таңдалады |
| SEO (canonical, JSON-LD) | Joomla ядросының плагиндері | өз қозғалтқышы |
| Мегамәзір | жоқ, кәдімгі ашылмалы тізімдер | `wm-mega…` токендері |
| PHP файлдары | 48 | 180-нен астам |

## Талаптар

- **Joomla 5.x немесе 6.x.** 6.2.0 нұсқасында тексерілген.
- Joomla 5 үшін **PHP 8.1 және жаңасы**, Joomla 6 үшін **8.3 және жаңасы** (ядроның талабы). Барлық файлдың синтаксисі PHP 8.5 нұсқасында тексерілген.
- **JUImage кітапханасы** (Joomla! Ukraine) — превьюді кесіп, сығады. Ол болмаса шаблон жұмыс істей береді, бірақ суреттерді түпнұсқа күйінде шығарады.
- UIkit 3.25.25 шаблонның ішінде бар, оны бөлек орнатудың қажеті жоқ.

## Орнату

1. [Шығарылымдар](https://github.com/bsakhanov/wmarka-clean/releases) бетінен `tpl_wmarka_clean-1.0.4.zip` мұрағатын жүктеп алыңыз.
2. Joomla әкімшілік панелі → **Жүйе → Кеңейтімдерді орнату → Пакет файлын жүктеу** → мұрағатты таңдаңыз.
3. **Жүйе → Сайт шаблондарының стильдері** → «wmarka_clean - Әдепкі» стилінің жұлдызшасын басыңыз: ол әдепкі стиль болады.
4. Сайтта JUImage әлі жоқ болса, оны орнатыңыз: `lib_juimage` мұрағаты [JUImage](https://github.com/Joomla-Ukraine/JUImage) шығарылымдарында және толық [wmarka](https://github.com/bsakhanov/wmarka/releases) пакетінің ішінде бар. Шаблон кітапхананы өзі табады.

> Стильді баптаудың қажеті жоқ: онда штаттық «Сипаттама» және «Мәзірге тағайындау» қойындыларынан басқа ештеңе жоқ.

**Жаңартулар.** Шаблонның жаңарту сервері бар: жаңа нұсқа **Жүйе → Жаңарту → Кеңейтімдер** бөлімінде көрінеді және сол жерден орнатылады. Еншілес шаблонға жаңарту тимейді.

## Алғашқы іске қосу қадам-қадаммен

**1. Мәзір.** Негізгі мәзірді жасаңыз (**Мәзірлер → Басқару → Жасау**) және оған пункттер қосыңыз. Жұлдызшамен белгіленген пункт — басты бет.

**2. Жоғарғы бөліктегі мәзір модулі.** **Мазмұн → Сайт модульдері → Жасау → Мәзір**: өз мәзіріңізді таңдаңыз, позиция — `navbar-right`, модуль стилі — «Әдепкі», «Тақырыпты көрсету» — жоқ. Навбар позицияларында мәзір көлденең шығады, ішкі пункттер ашылмалы тізімге жиналады. Телефонда сол мәзір үш сызықты батырманың астындағы мобильді панельде өзі пайда болады.

**3. Логотип.** Модуль болмаса, жоғарғы бөлікте **Жүйе → Жалпы баптаулар → Сайттың атауы** өрісіндегі атау тұрады. Сурет керек болса, `logo` позициясында «HTML-код» модулін жасаңыз (модуль стилі — әдепкі, тақырыпты көрсетпеу), мысалы:

```html
<a class="uk-navbar-item uk-logo" href="/"><img src="/images/logo.svg" width="160" height="40" alt="Сайттың атауы"></a>
```

**4. Навигация жолы.** «Сайт навигаторы» (breadcrumbs) модулін `breadcrumb` позициясына қойыңыз.

**5. Бүйірлік бағандар.** Модульдерді `sidebar-a` (сол жақ) және `sidebar-b` (оң жақ) позицияларына қойыңыз. Бүйірлік баған бос болмаса, мазмұн бағаны өзі тарылады: әр бүйірлік баған еннің төрттен бірін алады.

**6. Басты беттің блоктары.** Слайдер — `slider` позициясына, мазмұннан жоғарғы секциялар — `block-a`, `block-b`, мазмұннан төмен — `block-c`-ден `block-k`-ге дейін. Олардың қалай құрылатыны [«Блоктық позициялар»](#блоктық-позициялар) бөлімінде.

**7. Төменгі бөлік.** Үш баған — `footer-left`, `footer-center`, `footer-right`, авторлық құқық жолы — `footer`. Жыл мен сайттың атауын шаблон өзі жазады.

**8. Сайт белгішелері.** `favicon.svg`, `favicon.ico` және `apple-touch-icon.png` файлдарын `media/templates/site/wmarka_clean/images/favicon/` бумасына салыңыз — немесе еншілес шаблоныңыз болса, соның дәл осындай бумасына. Шаблон тапқан файлдарын шығарады.

**9. Іздеу.** «Ақылды іздеу» мәзір пункті (жасырын мәзірде болуы мүмкін) және кез келген позицияда «Ақылды іздеу» модулі керек. Индекс **Компоненттер → Ақылды іздеу → Индекстеу** арқылы немесе `php cli/joomla.php finder:index` командасымен жаңартылады.

## Блоктық позициялар

`adver-top`, `slider` және `block-a` … `block-k` позициялары бір ережеге бағынады.

- **Позициядағы барлық модульдің стилі «blank» болса,** шаблон айналасына ештеңе салмайды, модульдер беттің толық енімен шығады. Мұқабаларды, бейне блоктарды, жазылу жолақтарын осылай жасайды: модуль өз секциясын өзі анықтайды.
- **Олай болмаса,** шаблон позицияны өзі орайды: контейнері мен торы бар `uk-section` секциясы. Бағандар саны модульдер санына тең, бірақ төрттен аспайды; телефонда — біреу, 640 px-тен бастап — екеу. Беттегі әрбір екінші блоктық позицияның фоны күңгірт болады.
- **Модуль класының жұрнағы** `uk-width-…` баған енін өзгертеді. Мысалы, `uk-width-2-3@m` және `uk-width-1-3@m` жұрнақтары бар екі модуль жолды үштен екіге және үштен бірге бөледі.

Толық енді модульдің мысалы — `blank` стиліндегі «HTML-код»:

```html
<section class="uk-section uk-section-primary uk-light">
  <div class="uk-container">
    <h2>Жаңалықтарға жазылу</h2>
    <p>Аптасына бір рет — жеті күннің ең бастысы.</p>
  </div>
</section>
```

## Модуль стильдері

Модульдің ішінде таңдалады: **Қосымша → Модуль стилі**.

| Стиль | Сыртқы түрі |
|---|---|
| `clean` | сол жағында белгісі бар тақырып және мазмұн; бүйірлік бағандарда, блоктарда және төменгі бөлікте әдепкі стиль |
| `card` | тақырыбы бар UIkit ақ карточкасы |
| `blank` | ешқандай орамсыз; блоктық позицияда — толық енімен |

## Суреттер

Өлшемдер тікелей макеттерде жазылған — олар тек осы жерде сақталады:

| Макет | Өлшемдері | Қай жерде шығады |
|---|---|---|
| `html/layouts/joomla/content/intro_image.php` | **720 × 405** және **360 × 203** | блогтың, таңдаулылардың, тегтердің карточкалары; модульдердің тізімдері |
| `html/layouts/joomla/content/full_image.php` | **1200 × 675** және **720 × 405** | мақала |

Екі жұп та 16 : 9 пропорциясында, ортасынан кесіледі, пішімі WebP, сапасы 80. Браузер `srcset` ішінен файлды орынның еніне және экранның тығыздығына қарай өзі таңдайды. Дайын превьюлер сайт түбіріндегі `img/` бумасына жиналады.

Кіріспе суреті болмаса, карточка толық суретті алады. JUImage немесе файл болмаса, түпнұсқа шығады.

**Өлшемдерді қалай өзгертуге болады.** Макетті еншілес шаблонға көшіріңіз ([төменде](#өзіңізге-қарай-өзгерту) қараңыз) де, бір жолды түзетіңіз. Мысалы, `intro_image.php` ішінде 4 : 3 превью:

```php
echo T::img($src, [[800, 600], [400, 300]], $alt, '(min-width: 960px) 360px, (min-width: 640px) 50vw, 100vw', $class);
```

Өлшемдерді өзгерткен соң `img/` бумасын тазалаңыз: жаңа превьюлер беттер алғаш ашылғанда пайда болады.

## Не қайта анықталған

**Мақалалар**

- **Мақала.** Тақырыптың үстінде бір жолмен санат, `H1` тақырыбы, қызметтік жол (автор, күні, қаралым саны), толық сурет, мәтін. Мәтіндегі кестелер телефонда бағанмен тізіледі, әр мәннің жанында баған атауы тұрады; ұяшықтары біріктірілген кесте өз блогында айналдырылады. Одан әрі — тегтер мен мақалалар бойынша навигация. Мәзір пунктінің тақырыбы пункт дәл осы мақалаға апарғанда ғана басылады.
- **Санат блогы және таңдаулылар.** Жетекші материалдар — кең карточкамен, суреті сол жақта жарты енде. Қалғандары — тормен: телефонда бір баған, 640 px-тен екі, 960 px-тен үш. Төменде — басқа материалдарға сілтемелер және беттер бойынша навигация.
- **Санат тізімі.** Кесте: тақырып, күні, қаралым саны.

**Тегтер**

- **Тег** — блогтағыдай тормен орналасқан карточкалар.
- **Барлық тегтер** — сипаттамасы мен қаралым саны бар белгілер.

**Қалғандары**

- **Байланыс** — фото, аты-жөні, лауазымы, мекенжайы, хат жіберу формасы. **Байланыстар санаты** — дөңгелек фотолы карточкалар.
- **Ақылды іздеу** — белгішесі бар жол және миниатюралы нәтижелер.
- **Кіру және шығу** — карточкадағы формалар.
- **Модульдер:**
  - мәзір (навбарда көлденең, басқа позицияларда тік);
  - «Материалдар», «Соңғылары», «Танымалдары», «Санат материалдары», «Ұқсас материалдар» — миниатюралы тізім;
  - «Танымал тегтер» — белгілермен;
  - «Ақылды іздеу», «Кіру», «Сайт навигаторы».
- **Жалпы макеттер** — қызметтік жол, тегтер, «Толығырақ», UIkit беттер навигациясы.
- **Беттер:** қате беті, «Сайт жабық» және «Тек компонент».

Joomla ядросының опциялары — күнін, авторын, санатын, тегтерін көрсету-көрсетпеу, жетекші материалдар саны, беттегі материалдар саны — әдеттегідей жұмыс істейді: бұлар шаблонның емес, Joomla-ның баптаулары.

Шаблон қайта анықтамаған ядро белгілеуін (тіркелу, құпиясөзді қалпына келтіру, профиль, байланыс формасы) `media/css/clean.css` файлы UIkit мәнерінде безендіреді.

## Өзіңізге қарай өзгерту

**Шаблонның өзін емес, еншілес шаблонды (child template) түзетіңіз.** Шаблонды жаңарту оның бумасындағы файлдарды қайта жазады, ал еншілес шаблонға тимейді.

1. **Жүйе → Сайт шаблондары → wmarka_clean → Еншілес шаблон жасау.** Joomla манифесі бар `templates/wmarka_clean_<атау>/` бумасын және `media/templates/site/wmarka_clean_<атау>/` медиа бумасын жасайды.
2. Еншілес шаблонның стилін әдепкі стиль етіңіз.
3. Еншілес шаблонға тек өзгертетін файлдарыңызды көшіріңіз. Онда жоқтың бәрін Joomla ата-ана шаблоннан алады.

| Нені өзгерту керек | Еншілес шаблонға қай файлды көшіру керек |
|---|---|
| превью өлшемдері | `html/layouts/joomla/content/intro_image.php`, `full_image.php` |
| карточканың түрі | `html/layouts/clean/card.php` |
| блог бағандары (`uk-child-width-1-3@m`) | `html/layouts/clean/blog.php` |
| мақаланың түрі | `html/com_content/article/default.php` |
| жоғарғы бөлік, төменгі бөлік, блоктардың реті | `index.php` |
| түстер, шегіністер, дәйексөз | `media/css/clean.css` → еншілес шаблонның медиа бумасына, `css/clean.css` ретінде |

**UIkit түстері мен қаріптері.** UIkit тақырыбы толығымен `media/css/uikit.min.css` файлында. UIkit құжаттамасы бойынша (Less немесе Sass айнымалылары) өз тақырыбыңызды жинап, `uikit.min.css` файлын еншілес шаблонның медиа бумасына салыңыз: шаблон стандарттың орнына соны қосады.

**Өз скриптіңіз.** Файлды `media/templates/site/<еншілес>/js/` бумасына салып, өз `index.php` файлыңызда қосыңыз, мысалы `$wa->registerAndUseScript('my', 'media/templates/site/<еншілес>/js/my.js', [], ['defer' => true])` арқылы.

## wmarka-дан көшу

- **wmarka макеттері бар модульдер** («Материалдар» модуліндегі `wm-cards`, `wm-media`, `wm-feed`, `wm-slider`) жұмысын жалғастырады: clean ішінде аттас макеттер бар. Олар болмаса, Joomla модульдің штаттық макетінде тұйықталып қалар еді.
- **`wmarka:wm-team` сияқты баламалы макеттері бар мәзір пункттері** wmarka орнатулы тұрғанда жұмыс істейді. wmarka-ны өшіретін болсаңыз, мұндай пункттерді штаттық макеттерге ауыстырыңыз.
- **wmarka стилінің баптаулары** — байланыстар, SEO, превью өлшемдері — clean-ге көшпейді: мұнда олар жоқ. Canonical пен Schema.org белгілеуін ядроның «Жүйе — SEF» («Сайт домені» өрісі) және «Жүйе — Schema.org» плагиндері береді.
- **Токендермен жасалған мегамәзір** ашылмалы тізімдері бар кәдімгі мәзірге айналады.

## Тексерілгені

wmarka пакетіндегі «Вестник» демо-сайты бар таза Joomla 6.2.0 нұсқасында:

- 21 бет 200 кодымен жауап береді, жоқ мекенжай — 404, PHP хабарламалары жоқ;
- экран ені 375 және 1366 px, скриптпен де, скриптсіз де: бірде-бір бет экраннан кең емес, JavaScript қателері жоқ;
- JUImage превьюлерді дәл берілген өлшемде кесті: 720 × 405, 360 × 203, 1200 × 675;
- 48 PHP файлының бәрінің синтаксисі PHP 8.5.11 нұсқасында тексерілген.

## Тарихы

**J!Blank.** Бастауы — JBZoo командасының (Денис Сметанников, Сергей Калистратов, Евгений Копылов) [J!Blank](https://github.com/JBZoo-CCK/JBlank) дайындамасы: стильдерді өзі жасамайтын, бәрін әзірлеуші шешетін шаблон.

**wmarka 1.0 (2023 жылғы шілде) — 2.0.7 (2025 жылғы желтоқсан).** UIkit 3 негізіндегі «таза дерлік шаблон»: әкімшілік панельде бірде-бір баптау жоқ, конфигурация кодта (J!Blank-тың `php/init.php` файлы), ұйымның деректері — үш тілдегі тілдік қайта анықтауларда, блоктар — жеке партиалдарда, позициялар мен модуль стильдері — Алексей Морозовтың Master3 шаблонының үлгісімен. Жаңарту кодтағы түзетулерді өшіріп тастайтын, позициялар манифестте жарияланбаған еді — бұл сабақтар clean-де ескерілді.

**wmarka 3.0 (2026 жылғы наурыз) және 4.x (2026 жылғы қазан).** Шаблон «толық» шаблонға айналды: әкімшілік панельдегі баптаулар, өз SEO қозғалтқышы, мегамәзір, жаңалықтарды беру тәсілі, демо-пакет.

**wmarka clean 1.0.0 (2026 жылғы қазан).** 2.x тазалығына оның тұзақтарынсыз оралу: бәрі файлдарда, бірақ позициялар жарияланған, түзетулер еншілес шаблонда сақталады, ал 4.x-тен баптауды қажет етпейтін нәрселер алынды: блоктар ережесі, телефондағы кестелер, JUImage арқылы превью.
