# wmarka clean

**Русский** · [Қазақша](README.kk.md) · [English](README.en.md)

Чистый стартовый шаблон для Joomla 5 и 6 на UIkit 3 — **без единой настройки**. Раскладка страницы задана в `index.php`, размеры картинок — в двух макетах, оформление — в одном файле стилей. Всё, что нужно поменять, меняется в файлах, а не в админке.

Шаблон — чистая сборка [wmarka](https://github.com/bsakhanov/wmarka): те же позиции, тот же подход к блокам, таблицам и картинкам, но без панели на сто с лишним параметров, без SEO-движка и без мегаменю на токенах. Он для разработчика, который собирает сайт руками и хочет видеть каждую строку разметки.

| | wmarka clean | wmarka |
|---|---|---|
| Настройки в админке | нет | больше 120 параметров, опции в пунктах меню |
| Размеры превью | в макетах `intro_image.php` и `full_image.php` | в стиле шаблона |
| Блог, метки, статья | жёсткие макеты | вид выбирается в настройках |
| SEO (canonical, JSON-LD) | плагины ядра Joomla | свой движок |
| Мегаменю | нет, обычные выпадающие списки | токены `wm-mega…` |
| Файлов PHP | 48 | больше 180 |

## Требования

- **Joomla 5.x или 6.x.** Проверено на 6.2.0.
- **PHP 8.1 и новее** для Joomla 5, **8.3 и новее** для Joomla 6 (требование ядра). Синтаксис всех файлов проверен на PHP 8.5.
- **Библиотека JUImage** (Joomla! Ukraine) — режет и сжимает превью. Без неё шаблон работает, но выводит картинки оригиналами.
- UIkit 3.25.25 уже в шаблоне, ставить его отдельно не нужно.

## Установка

1. Скачайте `tpl_wmarka_clean-1.0.2.zip` со страницы [выпусков](https://github.com/bsakhanov/wmarka-clean/releases).
2. Админка Joomla → **Система → Установка расширений → Загрузить файл пакета** → выберите архив.
3. **Система → Стили шаблонов сайта** → у стиля «wmarka_clean - По умолчанию» нажмите звёздочку: он станет стилем по умолчанию.
4. Поставьте JUImage, если её ещё нет на сайте: архив `lib_juimage` есть в выпусках [JUImage](https://github.com/Joomla-Ukraine/JUImage) и внутри полного пакета [wmarka](https://github.com/bsakhanov/wmarka/releases). Шаблон найдёт библиотеку сам.

> Настраивать стиль не нужно: у него нет вкладок, кроме штатных «Описание» и «Назначение меню».

**Обновления.** У шаблона есть сервер обновлений: новая версия появится в **Система → Обновление → Расширения** и ставится оттуда. Дочерний шаблон обновление не трогает.

## Первый запуск шаг за шагом

**1. Меню.** Создайте главное меню (**Меню → Управление → Создать**) и пункты в нём. Пункт, отмеченный звёздочкой, — главная страница.

**2. Модуль меню в шапку.** **Содержимое → Модули сайта → Создать → Меню**: выберите своё меню, позиция `navbar-right`, стиль модуля «По умолчанию», «Показывать заголовок» — нет. В позициях навбара меню выводится горизонтально, с выпадающими списками для подпунктов. На телефоне то же меню само появляется в мобильной панели под кнопкой с тремя полосками.

**3. Логотип.** Без модуля в шапке стоит название сайта из **Система → Общие настройки → Название сайта**. Нужна картинка — создайте модуль «HTML-код» в позиции `logo` (стиль модуля — по умолчанию, заголовок не показывать), например:

```html
<a class="uk-navbar-item uk-logo" href="/"><img src="/images/logo.svg" width="160" height="40" alt="Название сайта"></a>
```

**4. Хлебные крошки.** Модуль «Навигатор сайта» (breadcrumbs) в позицию `breadcrumb`.

**5. Сайдбары.** Модули в `sidebar-a` (слева) и `sidebar-b` (справа). Колонка контента сама сужается, когда сайдбар не пуст: каждый сайдбар занимает четверть ширины.

**6. Блоки главной.** Слайдер — в `slider`, секции над контентом — в `block-a`, `block-b`, под контентом — от `block-c` до `block-k`. Как они строятся, читайте в разделе [«Блочные позиции»](#блочные-позиции).

**7. Подвал.** Три колонки — `footer-left`, `footer-center`, `footer-right`, строка копирайта — `footer`. Год и название сайта шаблон пишет сам.

**8. Значки сайта.** Положите `favicon.svg`, `favicon.ico` и `apple-touch-icon.png` в `media/templates/site/wmarka_clean/images/favicon/` — или в ту же папку дочернего шаблона, если он у вас есть. Шаблон выведет найденные файлы.

**9. Поиск.** Нужен пункт меню «Умный поиск» (можно в скрытом меню) и модуль «Умный поиск» в любой позиции. Индекс обновляется в **Компоненты → Умный поиск → Индексировать** или командой `php cli/joomla.php finder:index`.

## Позиции модулей

| Позиция | Где на странице |
|---|---|

| `logo` | вместо названия сайта в шапке |
| `navbar-center`, `navbar-right` | навбар: по центру и справа (меню) |
| `iconnav` | иконки справа в навбаре |
| `breadcrumb` | хлебные крошки под шапкой |
| `adver-top`, `slider`, `block-a`, `block-b` | блочные позиции над контентом |
| `main-top`, `main-bottom` | над компонентом и под ним, в колонке контента |
| `sidebar-a`, `sidebar-b` | левый и правый сайдбары |
| `block-c` … `block-k` | блочные позиции под контентом |
| `footer-left`, `footer-center`, `footer-right` | три колонки подвала |

| `debug` | самый низ страницы |

Все тридцать позиций объявлены в манифесте и видны в списке позиций менеджера модулей.

## Блочные позиции

Позиции `adver-top`, `slider` и `block-a` … `block-k` подчиняются одному правилу.

- **Все модули позиции со стилем «blank»** — шаблон ничего не рисует вокруг, модули идут во всю ширину страницы. Так делают обложки, видеоблоки, полосы с подпиской: модуль сам задаёт свою секцию.
- **Иначе** шаблон оборачивает позицию сам: секция `uk-section` с контейнером и сеткой. Колонок столько, сколько модулей, но не больше четырёх; на телефоне — одна, с 640 px — две. Каждая вторая блочная позиция на странице получает приглушённый фон.
- **Суффикс класса модуля** `uk-width-…` перебивает ширину колонки. Например, два модуля с суффиксами `uk-width-2-3@m` и `uk-width-1-3@m` разделят строку на две трети и треть.

Пример модуля во всю ширину — «HTML-код» со стилем `blank`:

```html
<section class="uk-section uk-section-primary uk-light">
  <div class="uk-container">
    <h2>Подписка на новости</h2>
    <p>Раз в неделю — главное за семь дней.</p>
  </div>
</section>
```

## Стили модулей

Выбираются в модуле: **Дополнительно → Стиль модуля**.

| Стиль | Как выглядит |
|---|---|
| `clean` | заголовок с маркером слева и содержимое; стиль по умолчанию в сайдбарах, блоках и подвале |
| `card` | белая карточка UIkit с заголовком |
| `blank` | без обёртки вообще; в блочной позиции — во всю ширину |

## Изображения

Размеры заданы прямо в макетах — это единственное место, где они живут:

| Макет | Размеры | Где выводится |
|---|---|---|
| `html/layouts/joomla/content/intro_image.php` | **720 × 405** и **360 × 203** | карточки блога, избранного, меток; списки модулей |
| `html/layouts/joomla/content/full_image.php` | **1200 × 675** и **720 × 405** | статья |

Обе пары — 16 : 9, обрезка по центру, формат WebP, качество 80. Браузер сам выбирает файл из `srcset` по ширине места и плотности экрана. Готовые превью складываются в папку `img/` в корне сайта.

Нет вступительного изображения — карточка берёт полное. Нет JUImage или файла — выводится оригинал.

**Как поменять размеры.** Скопируйте макет в дочерний шаблон (см. [ниже](#как-поменять-под-себя)) и поправьте одну строку. Например, превью 4 : 3 в `intro_image.php`:

```php
echo T::img($src, [[800, 600], [400, 300]], $alt, '(min-width: 960px) 360px, (min-width: 640px) 50vw, 100vw', $class);
```

После смены размеров очистите папку `img/`: новые превью появятся при первом заходе на страницы.

## Что переопределено

**Материалы**

- **Статья.** Рубрика строкой над заголовком, заголовок `H1`, служебная строка (автор, дата, просмотры), полное изображение, текст. Таблицы в тексте на телефоне идут столбиком, у каждого значения подпись столбца; таблица со слиянием ячеек прокручивается в своём блоке. Дальше — метки плашками и навигация по статьям. Заголовок пункта меню печатается, только если пункт ведёт на эту самую статью.
- **Блог категории и избранные.** Ведущие материалы — широкой карточкой, картинка слева на половину ширины. Остальные — сеткой: одна колонка на телефоне, две с 640 px, три с 960 px. Ниже — ссылки на прочие материалы и постраничная навигация.
- **Список категории.** Таблица: заголовок, дата, просмотры.

**Метки**

- **Метка** — карточки сеткой, как в блоге.
- **Все метки** — плашки с описанием и числом просмотров.

**Остальное**

- **Контакт** — фото, имя, должность, адрес, форма письма. **Категория контактов** — карточки с круглыми фото.
- **Умный поиск** — строка с иконкой и результаты с миниатюрами.
- **Вход и выход** — формы в карточке.
- **Модули**:
  - меню (горизонтальное в навбаре, вертикальное в остальных позициях);
  - «Материалы», «Последние», «Популярные», «Материалы категории», «Похожие материалы» — список с миниатюрами;
  - «Популярные метки» — плашками;
  - «Умный поиск», «Вход», «Навигатор сайта».
- **Общие макеты** — служебная строка, метки, «Читать дальше», постраничная навигация UIkit.
- **Страницы** ошибки, «Сайт закрыт» и «Только компонент».

Опции ядра Joomla — показывать ли дату, автора, рубрику, метки, сколько ведущих материалов и сколько на странице — действуют как обычно: это настройки Joomla, а не шаблона.

Разметку ядра, которую шаблон не переопределяет (регистрация, восстановление пароля, профиль, форма контакта), оформляет `media/css/clean.css` в духе UIkit.

## Как поменять под себя

**Правьте не сам шаблон, а дочерний.** Обновление шаблона перезапишет файлы в его папке, а дочерний шаблон оно не тронет.

1. **Система → Шаблоны сайта → wmarka_clean → Создать дочерний шаблон.** Joomla сделает папку `templates/wmarka_clean_<имя>/` с манифестом и медиапапку `media/templates/site/wmarka_clean_<имя>/`.
2. Сделайте стиль дочернего шаблона стилем по умолчанию.
3. Копируйте в дочерний шаблон только то, что меняете. Всего, чего у него нет, Joomla возьмёт у родителя.

| Что поменять | Какой файл скопировать в дочерний шаблон |
|---|---|
| размеры превью | `html/layouts/joomla/content/intro_image.php`, `full_image.php` |
| вид карточки | `html/layouts/clean/card.php` |
| колонки блога (`uk-child-width-1-3@m`) | `html/layouts/clean/blog.php` |
| вид статьи | `html/com_content/article/default.php` |
| шапку, подвал, порядок блоков | `index.php` |
| цвета, отступы, цитату | `media/css/clean.css` → в медиапапку дочернего шаблона, в `css/clean.css` |

**Цвета и шрифты UIkit.** Тема UIkit целиком — в `media/css/uikit.min.css`. Соберите свою тему по документации UIkit (переменные Less или Sass) и положите `uikit.min.css` в медиапапку дочернего шаблона: шаблон подключит её вместо стандартной.

**Свой скрипт.** Положите файл в `media/templates/site/<дочерний>/js/` и подключите в своём `index.php`, например через `$wa->registerAndUseScript('my', 'media/templates/site/<дочерний>/js/my.js', [], ['defer' => true])`.

## Переход с wmarka

- **Модули с макетами wmarka** (`wm-cards`, `wm-media`, `wm-feed`, `wm-slider` у модуля «Материалы») продолжат работать: в clean есть одноимённые макеты. Без них Joomla зациклилась бы на штатном макете модуля.
- **Пункты меню с альтернативными макетами** вида `wmarka:wm-team` работают, пока wmarka установлен. Если удаляете wmarka, переведите такие пункты на штатные макеты.
- **Настройки стиля wmarka** — контакты, SEO, размеры превью — в clean не переносятся: их здесь нет. Canonical и разметку Schema.org берут плагины ядра «Система — SEF» (поле «Домен сайта») и «Система — Schema.org».
- **Мегаменю на токенах** превратится в обычное меню с выпадающими списками.

## Проверено

На чистой Joomla 6.2.0 с демо-сайтом «Вестник» из пакета wmarka:

- 21 страница отвечает 200, несуществующий адрес — 404, сообщений PHP нет;
- ширина экрана 375 и 1366 px, со скриптами и без: ни одна страница не шире экрана, ошибок JavaScript нет;
- JUImage нарезала превью ровно заданных размеров: 720 × 405, 360 × 203, 1200 × 675;
- синтаксис всех 48 файлов PHP проверен на PHP 8.5.11.

## История

**J!Blank.** Начало — заготовка [J!Blank](https://github.com/JBZoo-CCK/JBlank) команды JBZoo (Денис Сметанников, Сергей Калистратов, Евгений Копылов): шаблон без генерации стилей, где всё решает разработчик.

**wmarka 1.0 (июль 2023) — 2.0.7 (декабрь 2025).** «Почти чистый шаблон» на UIkit 3: ни одной настройки в админке, конфигурация в коде (`php/init.php` от J!Blank), данные организации — в языковых переопределениях на трёх языках, блоки — отдельными партиалами, позиции и стили модулей — по образцу шаблона Master3 Алексея Морозова. Обновление стирало правки в коде, позиции не были объявлены в манифесте — эти уроки учтены в clean.

**wmarka 3.0 (март 2026) и 4.x (октябрь 2026).** Шаблон вырос в «полный»: настройки в админке, свой SEO-движок, мегаменю, новостная подача, демо-пакет.

**wmarka clean 1.0.0 (октябрь 2026).** Возвращение к чистоте 2.x — без её ловушек: всё в файлах, но позиции объявлены, правки живут в дочернем шаблоне, а от 4.x взято то, что не требует настроек: правило блоков, таблицы на телефоне, превью через JUImage.
